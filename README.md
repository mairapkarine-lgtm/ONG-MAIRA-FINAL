# ONG MÁIRA

Projeto front-end acadêmico da ONG MÁIRA, desenvolvido com HTML5, CSS3 e JavaScript.

## Acessibilidade

- Estrutura semântica com `header`, `nav`, `main` e `footer`.
- Navegação por teclado e estados visuais de foco.
- Atributos WAI-ARIA no menu e em componentes interativos.
- Validação de formulário com indicação de campos inválidos.
- Suporte a `prefers-color-scheme: dark` e `prefers-contrast: more`.
- Respeito a `prefers-reduced-motion`.

## Build de produção

O projeto utiliza Vite para a build de produção. O comando `npm run build` gera a pasta `dist`, aplicando minificação aos recursos.

## Publicação

A aplicação pode ser publicada como site estático no GitHub Pages a partir do repositório do projeto.
